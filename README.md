# Melnitskyi

# Система Адаптивного Підбору Автомобілів Каршерингу

Кваліфікаційна робота бакалавра з розробки методу адаптивного підбору автомобілів каршерингу з інтеграцією технологій штучного інтелекту на основі алгоритмів градієнтного бустингу XGBoost.

---

## 1. ОГЛЯД МЕТОДУ

З огляду на зростаючу популярність каршерингових сервісів та необхідність оптимізації розподілу транспортних засобів у міському середовищі, актуальною є задача адаптивного підбору автомобілів з урахуванням індивідуальних вподобань користувачів. У роботі розглядається підхід машинного навчання на основі градієнтного бустингу XGBoost для прогнозування попиту та персоналізованого ранжування автомобілів. Метою дослідження є підвищення ефективності використання автопарку та якості обслуговування користувачів шляхом створення методу адаптивного підбору з подальшою розробкою інформаційної системи та її експериментальним аналізом.

### Опис вмісту:

*	data_processing.py - модуль обробки даних та створення ознак для машинного навчання

*	xgboost_predictor.py - реалізація XGBoost моделей для прогнозування попиту та ранжування

*	car_optimizer.py - алгоритми оптимізації розподілу автомобілів та формування рекомендацій

*	utils.py - допоміжні функції та утиліти для роботи з даними та метриками

*	app.py - Flask веб-додаток для взаємодії з системою через веб-інтерфейс

*	train_models.py - скрипт навчання ML моделей на підготовлених наборах даних
  
*	evaluate_system.py - модуль експериментальної оцінки ефективності системи
  
*	config.yaml - файл конфігурації з параметрами системи та налаштуваннями моделей
  
*	requirements.txt - список Python залежностей та бібліотек для роботи системи

## 2. ВСТАНОВЛЕННЯ ТА ЗАПУСК

Для роботи рекомендовано встановити віртуальне середовище.

### 1. Створення середовища:
python -m venv venv

### 2. Активація середовища:
venv\Scripts\activate

### 3. Встановлення залежностей:
pip install xgboost pandas numpy scikit-learn
pip install matplotlib seaborn geopandas
pip install flask pyyaml prophet pytest

### 4. Запуск системи:
python train_models.py
python app.py
python evaluate_system.py

## 3. ВИКОРИСТАННЯ СИСТЕМИ

Після запуску застосунку відбувається ініціювання процесу адаптивного підбору автомобілів з використанням моделей XGBoost. Система аналізує дані про користувачів, автомобілі та історію поїздок, виконує прогнозування попиту та формує персоналізовані рекомендації. Для візуалізації використовується веб-інтерфейс з інтерактивними картами та рейтингованими списками автомобілів.

## 4. ОСОБЛИВОСТІ РЕАЛІЗАЦІЇ

* Адаптивність: система автоматично адаптується до змін у поведінці користувачів
* Модульність: кожен функціональний блок реалізований окремо
* Продуктивність: час відгуку менше 0.5 секунди при обробці запитів
* Персоналізація: врахування індивідуальних вподобань користувачів
* Просторово-часовий аналіз: врахування географічних та часових факторів
* Швидкий старт: система готова до роботи після простих команд встановлення
* Сумісність: підтримка різних операційних систем

## 5. ПРИКЛАДИ ВИКОРИСТАННЯ

* оптимізація автопарку каршерингових компаній для максимізації використання
* персоналізовані рекомендації для користувачів з урахуванням вподобань
* прогнозування попиту в різних районах міста для планування розміщення
* динамічне ціноутворення на основі прогнозованого попиту
* аналіз ефективності роботи каршерингового сервісу з генерацією звітів
